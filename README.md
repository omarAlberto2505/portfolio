# Portfolio Website

This is a React portfolio website built with Vite.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the local URL shown by Vite.

## Build

- `npm run build` — create a production build in `dist/`
- `npm run preview` — preview the production build locally

## Files

- `index.html` — Vite entry point
- `src/main.jsx` — React app bootstrap
- `src/App.jsx` — portfolio layout and content
- `src/styles.css` — site styling
- `vite.config.js` — Vite React plugin configuration

## Deploy

Push this repository to GitHub and enable GitHub Pages on the `main` branch.
If you want the site to publish at `https://<username>.github.io/`, name the repo `<username>.github.io`.
